ML-Based Intrusion Detection & Prevention Evaluation
Kanto Gakuin University  ·  Sep 2022 – Mar 2024
01

A two-year research effort that fundamentally shaped my approach to cybersecurity. Driven by a strong interest in IDPS, I implemented and evaluated multiple machine learning algorithms against the CICIDS2017 dataset to understand how ML can address real-world network security challenges — and where it falls short.

Key Contributions
  • Implemented four ML algorithms: SVM, Naive Bayes, Decision Tree, and k-Nearest Neighbors
  • Conducted binary classification experiments using precision and recall as primary metrics
  • Developed ~10 Python source files, each exceeding 1,000 lines of code
  • Identified gaps between theoretical performance and real-world false positive rates on normal traffic
  • Iteratively refined experiments through continuous trial and error over two academic years
  • Gained a realistic perspective on operational IDPS deployment challenges
